# AI Passport 应用代码开发需求（第一阶段）

日期：2026-11-06。状态：基于已讨论 UX 的开发需求，不代表功能已经实现或通过真机验证。

## 已确认的第三阶段扩展：天气与联网校时

七入口菜单在音乐遥控之后增加天气查看，显示城市、天气、温度、体感、湿度、
风速及更新时间。确定请求刷新，长按确定返回菜单。离线显示缓存，首次未成功更新
时显示明确的空状态。名片天气区域共用同一份城市、天气情况和温度。

系统设置将原热点改称 Hotspot 开关／信息，新增独立的外部 Wi-Fi 开关／信息。
八项设置在六行窗口中滚动。热点名称及管理地址不变，仅通过 `http://192.168.4.1`
的本地网页选择网络和输入外部 Wi-Fi 密码。两开关独立；Hotspot 开机默认关闭，
外部 Wi-Fi 开关和凭据重启后保留。

网页天气城市只提供深圳、武汉，默认深圳。更新频率为 30、60、120、240 分钟，
默认 30 分钟并保存。每次开机联网校时成功一次后在本地计时；离线开机显示标记的
缓存时间，没有缓存则提示等待校时。本扩展取代早期天气／时间暂缓范围，验证见
[应用指南](../development/passport-card-remote.zh_CN.md)。

## 已确认的第二阶段扩展

后续确认的 Wi-Fi UX 取代下文第一阶段“资料／照片导入暂不开发”的范围。
增加 **Passport WIFI** 本地热点、Wi-Fi 开关和信息页，在 `http://192.168.4.1`
提供内置管理网页。可编辑头像、名字、星座、属相、今日标签，并管理最多六张照片。
信息页在 Wi-Fi 关闭时仍显示名称、配置密码和地址；密码不写入受版本控制的需求／源码。
名片需要预览与明确保存，照片删除二次确认。JPG／PNG 等比完整显示，保存后重启保留。
每次开机 Wi-Fi 默认关闭；天气编辑与真实乘车码仍不开发。
实现及验证记录见[应用指南](../development/passport-card-remote.zh_CN.md)。
以下内容保留原第一阶段基线。

## 1. 开发目标与范围

基于默认硬件，实现中文个人名片、Android QQ 音乐遥控、照片查看与系统设置。开机直接进入个人名片，复用 BSP，按讨论后的 UX 重新实现应用界面，不沿用硬件测试 demo 的视觉外壳。

| 模块 | 第一阶段范围 |
| --- | --- |
| 个人名片 | 内置可替换示例资料、今日标签、默认天气，无详情页 |
| 音乐遥控 | BLE 媒体按键、连接状态、手机音量调节 |
| 照片查看 | 最多 6 张内置示例图片、手动翻图、全屏切换 |
| 系统设置 | 自动息屏、蓝牙开关、进入配对模式、清除配对记录 |
| 地铁码与公交码 | 仅保留菜单入口和 UX 占位页面；真实功能暂不开发 |
| 个人资料设置与照片导入 | 暂不开发，手机／电脑配套工具及传输接口放到下一阶段 |

歌曲信息同步、实时天气、照片自动播放、高铁码暂不开发。本需求不定义资料／照片导入协议或乘车码接入方案，不提供伪导入按钮。

## 2. 页面与通用按键规则

屏幕为 240 × 320 竖屏，应用按键为上、确定、下。Power 为独立硬件键。

- 功能菜单依次包含：个人名片、音乐遥控、照片查看、地铁码、公交码、系统设置。
- 菜单上／下移动选中项，首尾循环；确定进入。菜单长按确定返回名片。
- 各功能页长按确定返回菜单；系统设置子页长按确定返回设置列表，设置列表长按确定返回菜单。
- 长按阈值默认采用 UX 的 0.5 秒，同一次按压不得同时触发长按与短按。
- 除音乐音量外，不为长按上／下增加快捷功能。

## 3. 个人名片页

- 显示日期、星期、电量、默认头像、示例姓名“小帕同学”、星座、属相。
- 名片上半区按约 60:40 分栏：头像加宽，姓名／星座／属相整体右移；两栏保留间距。日期、电量和下方标签区域保留。
- 下方在“今日标签”和“今日天气”之间翻页，上／下均可切换。
- 标签默认“保持好奇 · 慢慢来”；天气使用深圳固定示例，并明确标注默认值，不表达实时天气。
- 短按确定无附加动作，无名片详情页。
- 示例资料与文案集中配置，方便以后替换；手机／电脑修改资料、标签和天气的功能暂不开发。
- 日期、电量使用已有可用能力；无有效时间或电量读数时显示明确占位，不将示例值当作真实读数。新增校时工具暂不开发。

## 4. 音乐遥控页

通过 ESP32-C3 支持的 BLE 媒体控制方式遥控 Android 手机，优先验收 QQ 音乐；不在本机播放音频。

| 按键 | 行为 |
| --- | --- |
| 短按上 | 上一首 |
| 短按下 | 下一首 |
| 短按确定 | 播放／暂停 |
| 长按上 | 手机音量增加一档，保持按住每 3 秒再增加一档 |
| 长按下 | 手机音量减少一档，保持按住每 3 秒再减少一档 |
| 长按确定 | 返回功能菜单 |

- 达到长按阈值时发送首次音量指令，以此为起点每隔 3 秒重复；松开立即停止，不积压或补发。
- 每档由手机系统决定，不保证 5%，不显示未经同步的精确音量百分比。
- 歌曲区域固定显示“歌曲信息待同步”；歌曲名、歌手、封面、进度暂不开发。
- 右上角仅显示电量；采用设备名、歌曲信息卡片和三列遥控图标的布局。
- 连接状态显示在中间歌曲卡片内；断线后留在此页并显示“未连接”，不自动跳页。
- “播放／暂停”文字上方显示空心圆，与上一首／下一首图标对齐；底部保留音量规则、蓝牙配对指引和长按确定菜单提示。
- 操作提示使用“短按换歌/长按调整音量”并居中显示；成功提交上一首／下一首指令时，居中反馈对应的“上一首”“下一首”，不显示通用发送提示。长按音量仍每 3 秒重复一档。
- 蓝牙关闭或未连接时不发控制指令，提供简短提示。
- 无手机状态反馈时，不将本地切换的播放图标作为真实播放状态的保证。
- 重新配对通过系统设置进入，不增加双击等隐藏手势。

## 5. 照片查看页

- 最多 6 张，第一阶段使用固件内置示例图片。
- 上／下手动翻图，首尾循环；确定进入全屏，再次确定退出。
- 普通模式和全屏均等比完整显示，比例不同时留边，不裁切、不拉伸。
- 普通模式可显示当前张数／总数；全屏隐藏标题、计数和提示，仍支持上／下翻图及长按确定返回菜单。
- 不显示文件名、拍摄时间或照片信息，不提供自动播放。
- 0 张时显示“暂无照片”，翻页和确定不进入无效状态。
- 照片导入、删除、传输、格式转换及手机／电脑工具暂不开发。

## 6. 乘车码：仅保留 UX

- 地铁码、公交码保留独立入口与占位页面，不保留高铁码。
- 占位页面醒目标识“演示码 · 不可乘车”，不得放入真实票码或授权数据。
- 上／下可切换两个占位页；短按确定无业务动作，长按确定返回菜单。
- 页面保持常亮，离开后恢复用户设置的自动息屏策略。
- 支付宝接入、手机联动、真实二维码、刷新、有效期、支付及导入功能均暂不开发。

## 7. 系统设置页

设置列表依次为“自动息屏”“蓝牙”“进入配对模式”“清除配对记录”。上／下选择，确定执行或进入子页。

### 7.1 自动息屏

- 选项：15 秒／30 秒／60 秒／常亮；出厂默认 15 秒。
- 确定后立即生效并持久化，下次开机恢复；长按确定取消未确认选择并返回。
- 普通页面无按键操作达到时限时息屏，按键活动重置计时。息屏保留页面及 BLE 连接能力，不等同于整机休眠。
- 息屏后的第一次按键只唤醒；该次按压直到松开全部消费，不翻页、不调音量、不播放、不打开菜单。
- 唤醒后恢复原页面并重新计时；乘车码占位页豁免自动息屏。

### 7.2 蓝牙与配对

- 关闭蓝牙：断开连接、停止可连接广播，保留配对记录。
- 实现默认值：首次开机蓝牙开启，持久化用户开关选择；再次开启允许已配对手机重连。
- 蓝牙关闭时选择配对，提示先开启蓝牙。
- 进入配对模式后，Android 可在系统蓝牙设置中发现并配对；如需断开当前连接，页面明确显示待配对状态。
- 配对页显示设备名称及手机操作指引，不依赖下一阶段配套工具；连接成功后返回设置列表并更新状态。
- 离开配对页不清除已有绑定，具体重连策略及兼容性需在实现时验证。
- 清除配对需要二次确认，默认选中“取消”；取消保留记录，确认后断开并清除本机蓝牙绑定。
- 仅清蓝牙配对，保留资料、照片、自动息屏和其他设置。
- 手机残留旧绑定时，提示在 Android 端忽略旧设备后重新配对。

## 8. Power 键：硬件验证前置

- 目标交互：任何页面短按 Power 息屏，再次短按唤醒；长按关机和开机。
- 短按是否可被固件检测尚未确认，需检查硬件与 BSP 并真机验证，不能按普通三键能力推断。
- 若不支持，报告阻塞及替代建议，另行确认；不得擅自占用现有三键手势替代。
- 长按遵循现有硬件开关机行为，不擅自更改硬件时序。
- 乘车码“常亮”仅豁免自动息屏；Power 短按若可用，用户主动息屏优先。

## 9. 实现约束

- 复用 BSP 显示、按键、电量与背光能力。硬件通用能力放 `components/bsp`，页面、状态机和 BLE 应用逻辑放 `main`。
- 中文需验证字体字形覆盖、控件字体绑定和真机渲染，避免方框、空白与裁切。
- 按键回调不阻塞，耗时操作交给工作任务；跨 LVGL 任务访问 UI 必须持锁。页面销毁前停止相关任务、定时器及回调。
- 导航、长短按、3 秒重复、唤醒消费、自动息屏、设置持久化规则须可做独立 host tests。
- 设置缺失或无效时恢复默认，避免将空闲计时变化频繁写入 Flash。
- 不新增导入或乘车码协议，不提交个人资料、票码秘密或未脱敏日志。

## 10. 验收与交付

| 验收项 | 通过条件 |
| --- | --- |
| 启动与导航 | 冷启动进入名片；六项菜单及返回路径正确，无高铁入口 |
| 名片 | 标签／默认天气正常切换，确定无详情；中文完整无裁切 |
| 音乐 | Android QQ 音乐上一首、下一首、播放暂停实测有效；断线留页 |
| 音量 | 首次长按一档、后续每 3 秒一档、松开即停；未连接不发指令 |
| 照片 | 0／1／6 张边界、循环翻图、全屏进退、等比留边正确 |
| 息屏 | 四选项、15 秒默认、重启保持、唤醒首按消费全部正确 |
| 蓝牙 | 开关、首次配对、重连、确认／取消清除有效；仅清除绑定 |
| 乘车码 UX | 明确不可乘车、保持常亮、退出恢复自动息屏 |
| Power | 独立记录短按硬件验证、长按开关机结果，不以 UX 模拟代替 |

固件实现交付时运行静态检查、host tests、固件构建和完整验证门禁，分别报告 Build、Host tests、Device tests、Unverified。交付经验证可从 `0x0` 刷写的合并固件与匹配调试产物；主动询问是否刷机测试，得到授权后才烧录。

本文件定义需求；实现与验证记录见[应用说明](../development/passport-card-remote.zh_CN.md)。旧版应用的测试结果不视为本需求的验收结果。
